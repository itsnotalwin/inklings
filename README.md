# INKLINGS · The Nest

A cozy, mobile-first illustrated creature-care game for GitHub Pages. Meet Pip and Momo, feed them, play and keep a tiny journal. No levels, timers, accounts or punishment.

## Run
Open `index.html` via a local static server (`python -m http.server 8080`) or use GitHub Pages.

## Status
Early playable vertical slice. See `PROJECT.md` for current features and limitations.
