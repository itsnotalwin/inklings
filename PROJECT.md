# INKLINGS · Project handoff

Status: playable source pushed as initial GitHub bootstrap on 2026-11-04; Pages activation and live verification pending.

Goal: art-first watercolor Tamagotchi-style illustrated nest on mobile. No levels, lives, deadlines or monetization.

Stack: static HTML, CSS and JavaScript with painted raster art. No packages or external dependencies.

Run: `python -m http.server 8080` from repository root.

Design: full-illustration home screen with actual interactive Play/Journal/Settings hotspots; after Play, Pip and Momo can be petted, fed and played with. Journal and Settings dialogs use paper styling.

Known limitations: characters animate in place and need original poses/autonomous movement and retouching. Browser saves are device-specific. GitHub Pages publication must be enabled and verified separately.

Next actions: publish Pages, inspect mobile UI live, produce higher-fidelity animation sprites and richer creature behaviours.
